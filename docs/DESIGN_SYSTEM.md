# 设计系统

## 表达
“折射”是数据关系：价值权重改变，各个方案的彩色贡献段随之伸缩。不是背景粒子或随机炫技。工作室采用纸质实验笔记的安静尺度，保留中文叙事和少量等宽实验编号。

背景 #f3f2ec；文字 #283d35；苔绿 #315d4c；陶土强调 #d16e4e；视角颜色按顺序固定，文字与数字同时表达，不只靠颜色。字体为系统中文 sans、系统宋体/Georgia 标题，不依赖远程字体。

桌面左侧问题架、中央方案、右侧视角。800px 以下变为横向问题架；580px 以下视角置于方案后。基本间距 4/8/12/18/24/32。按钮明确区分主行动、次行动与辅助操作。

## 状态与交互
权重与基础分先在本地预演；细线是已保存基线，彩色条是当前草稿。领先翻转有文字提示。保存需显式操作，Ctrl/Cmd+S 可用。切换、刷新、关闭窗口提醒未保存状态。
锁定的原生表单 disabled，页面说明只读；后端同时强制执行。空态说明如何进入；示例通过用户明确选择创建。错误保留输入，反馈既有 toast 也有持久错误区。不可逆证据删除需确认，归档可恢复。

模态框管理焦点、Escape、语义标题；主导航、tab、表格、标签使用原生语义；skip link 直达工作区；焦点轮廓可见。动画仅为评分宽度 250ms 与加载反馈，prefers-reduced-motion 时取消。
