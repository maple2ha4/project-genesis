# 产品愿景与方向选择

## 探索边界与调研
2026-10-27，在空仓库开始研发。依赖注册表与 Maven Central 可访问；访问 https://www.kialo.com 、https://www.loomio.com 、https://untools.co/decision-matrix/ 均被代理以 403 拒绝。没有可用网页搜索工具。因此下述竞品描述是已知产品类别的背景知识，不是本次成功抓取的市场调研；不能据此宣称全球首创。

## 三个候选构想

### A. 折光 PRISM：可检验的选择
1. 是什么：把选择的价值权重、证据和实践反馈放在同一个连续工作空间。
2. 值得存在：人们经常忘记当初为何选择，结果出来后又重写自己的记忆。
3. 缺失体验：在行动之前看见价值取舍，在行动之后保留与修正判断。
4. 常见处理：表格决策矩阵、利弊清单、论证树或会议投票。Kialo 属论证组织类，Loomio 属协作决策类；本次未验证其最新功能。
5. 根本区别：权重变化引发可见的领先翻转；证据真实改变评分；锁定假设与快照后必须通过复盘完成闭环。
6. 价值：把“找一个最高分”改为“理解我的偏好与未知，再做可检验实践”。
7. 技术：Vue 响应式本地预演、Java 权威规则、H2 事务、版本冲突检测。
8. 产品风险：虚假的精确感，用户会把主观评分当成事实。
9. 工程风险：前后端公式漂移、锁定后历史被重写、并发覆盖。
10. 难忘时刻：轻移“持续运转”的滑块，喜欢的方案退后；用户意识到下一步需要证据，而非漂亮答案。

### B. 潮汐档案：信息衰变地图
1. 是什么：按“多久后需要重查”组织个人事实与来源。
2. 值得存在：收藏夹无法区分仍然可靠与已经过时的资料。
3. 缺失体验：内容通过时效而非文件夹变得可见。
4. 常见处理：收藏、阅读稍后、知识库标签，人工检查链接。
5. 根本区别：每项事实有衰变曲线与重新核实仪式。
6. 价值：减少过期资料误用，突出需要重新验证的知识。
7. 技术：Java 定时器、来源抓取、Vue 时间地图、数据库。
8. 产品风险：不同领域的有效期不能靠统一衰减准确表达。
9. 工程风险：抓取受限、版权、恶意 URL 与 SSRF、来源长期变化。
10. 难忘时刻：地图随时间露出需要重新求证的知识裂隙。

### C. 回声剧场：情境记忆重构
1. 是什么：用少量自写片段构建可以沿场景、声音、时间重访的私密记忆空间。
2. 值得存在：相册按日期整理，未必保留事件的意义关系。
3. 缺失体验：从一种感受回到关联的地点、人和事件，而不是搜索文件名。
4. 常见处理：日记、相册、卡片式笔记与双链网络。
5. 根本区别：用户主动编排可重放的情境路径，而非机器自动叙事。
6. 价值：保存个人叙事的细节与不同视角。
7. 技术：Vue 空间交互、媒体文件管理、Java 私有存储。
8. 产品风险：录入负担高，空间隐喻未必比列表更易理解。
9. 工程风险：媒体存储、隐私泄漏、浏览器音视频兼容与无障碍。
10. 难忘时刻：从一段声音走向一段被遗忘的关联。

## 决策
选择 A。三者都有视觉潜力，A 的明确价值、概念完整性、可验证工程闭环和维护成本更平衡。B 的核心价值依赖尚未可靠解决的真实性与时效模型；C 需要真实媒体与持续使用才能检验价值，目前容易沦为体验演示。A 不一定是原创性评分最高的构想，但可以把差异做进真实规则，而非装饰层。

## 核心体验与边界
目标用户：正在做有现实后果、可以小规模试行的个人选择的人；单人自托管。场景：社区空间用途、创作方式、学习路线等可复盘问题。
核心旅程：展开问题 → 2–5 个方案、2–6 个视角 → 基础判断 → 调权观察敏感度 → 收集证据 → 保存 → 选择并锁定假设/信号/日期 → 实践 → 复盘 → 新一轮。
不可缺：真实存储、透明评分、证据、不可变快照、复盘、恢复与备份、错误与冲突保护。
可选后续：跨轮次分析、经过用户研究的连续敏感度图、多语言。
明确不做：通用任务清单、协作社交、AI 自动替用户决策、账户注册、内容抓取、预测成功概率。
视觉：纸、石墨、苔绿与陶土色，细线光谱表达成分，动态只呈现判断变化。
成功：用户能够解释一次排名改变；完成从问题到复盘的闭环；刷新/重启不丢数据；另一名开发者可独立运行。没有真实用户研究时不宣称已证实用户价值。
