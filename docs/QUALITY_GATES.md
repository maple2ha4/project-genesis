# 质量门槛与验收

这些门槛针对单人、有限规模的私有工作室；不能用静态画面或零测试运行替代。

| 领域 | 可检验门槛 | 最终结果 |
|---|---|---|
| 核心价值 | 权重调整产生领先翻转；证据改变评分；锁定→实践→复盘→新一轮完整可走通 | 通过：真实 Chromium + Java 独立规则测试 |
| 真实业务 | Vue 通过 Java API 读写 H2，刷新后记录仍存在 | 通过：浏览器流程与文件库测试 |
| 历史可靠性 | 锁定后不能改写评分/证据；复盘保留当时快照 | 通过：服务端/界面双约束，快照比较 |
| 生命周期 | 创建编辑、归档恢复、确认永久删除闭环 | 通过：Java 与浏览器测试 |
| 异常与冲突 | 400/401/403/404/409/413/422 有正确结果；相同版本并发只允许一个成功 | 通过：集成 API 与真实 HTTP 200/409 |
| 测试 | 必要 Java/Vue 测试全部通过，核心浏览器流程实际执行，无跳过或零测试冒充 | 通过：13 Java、5 Vue、5 浏览器；详见 TESTING |
| 数据持久化 | 完整复盘记录在进程停止/重启后结构一致 | 通过：真实临时文件库逐字段比较 |
| 恢复 | JSON 导入不覆盖原有数据；无效导入整批回滚；容器停机文件备份恢复后业务可读 | 通过：服务测试、真实 HTTP、Compose |
| 性能 | 当前机器31项记录连续30次列表读取 p95 <300ms；主 JS gzip <80KB、CSS gzip <12KB | 通过：本次22.7ms；资产见 verification.json；不是全规模基准 |
| 安全 | 私有模式未认证/错误密码401，正确身份能写；CSRF、参数化查询、请求上限、安全头、非本地无凭据拒绝启动 | 通过：JUnit、打包运行与浏览器私有登录 |
| 依赖 | npm audit 无已知漏洞；下载保留校验与 TLS | 通过：本次0，范围不含全部 Java/系统镜像 CVE |
| 可用性 | 加载/空态/表单/网络错误/重试/成功可见，失败不自动重写用户草稿 | 通过：组件实现、浏览器503恢复、保存提示 |
| 响应式 | 390px 核心路径可用且页面不横向溢出；桌面实图检查 | 通过：真实 Chromium 截图与 scrollWidth 断言 |
| 无障碍 | 3工作区的 WCAG A/AA 标签规则零违规；键盘 tab 导航、焦点、Escape 与减少动态效果 | 自动规则与键盘测试通过；不是全面人工认证 |
| 构建部署 | 冻结 npm 安装、类型检查、可执行 Java 包、源码 Docker 构建、Compose 健康与认证业务 | 当前机器通过；新机器/公网部署未验证 |
| 文档恢复 | 必要中文文档、运行/测试/备份/恢复命令、当前任务状态完整 | 已提供；环境草稿已保存，未发布 |

不阻止本机版本交付的明确限制：无真实市场调研/用户研究，没有远程 CI 结果、无全库镜像安全扫描、未验证新机器恢复与公网 HTTPS。不得将这些状态标为通过。本版本不提供多人、提醒、AI 自动决策或无限规模承诺。
