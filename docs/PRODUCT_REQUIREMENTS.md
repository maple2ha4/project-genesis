# 产品需求

## 身份与边界
单人私有工作室，共享一个完整数据空间，不提供多用户隔离或注册。loopback 开发可免认证；非 loopback 启动必须配置工作室所有者凭据。所有者可访问全部记录。

## 核心流程
- 空工作室可创建真实问题，也可明确选择载入虚构街区示例，不自动污染数据。
- 标题 1–100 字、问题 1–2000 字、时间范围 0–100 字；方案 2–5 个、视角 2–6 个。视角统一采用越高越好的口径。
- 基础分 0–10，权重 0–100，全部权重不能为零。滑块即时预演，显式保存，刷新和切换提醒未保存调整。
- 每条证据关联一个方案及视角，影响 −3 至 3，信心 0–1，证据内容 1–1000 字，最多 100 条；删除需要确认并撤销影响。
- 分数为各视角的 clamp(基础分 + Σ影响×信心, 0, 10) × 归一化权重之和。不是概率。同分按方案 ID 稳定排序，不表达统计意义。
- 敏感度以五个权重采样点测试是否更换领先方案；界面如实告知采样限制，不声称精确临界值。
- 锁定必须选择方案、写假设与成功信号、填写不早于 UTC 今天的复盘日期；保存当时评分和视角，之后禁止改分、改证据或元信息。
- 实践可提前复盘，日期是约定而非执行门禁。复盘有支持/混合/推翻三类结论，必须记录观察；不覆盖快照。
- 归档可逆；归档不删除数据。新一轮复制基础判断与视角，不复制需要重新验证的证据，不承诺自动学习。
- 导出全部 JSON；导入格式 1，每次 1–50 项、512 KB，生成新记录，不覆盖旧记录；全工作室上限 500 项。大型工作室通过数据库备份恢复。

## 质量与状态
等待、空态、网络错误、表单错误、保存反馈、401 登录、409 冲突都需可见。冲突不自动覆盖用户草稿，用户可重新加载。桌面与 390px 移动设备核心操作可用；模态框焦点约束与 Escape；原生输入键盘可操作；减少动态效果偏好受尊重。

## 不属于本版本
多人协作、服务器推送、邮件提醒、长期后台任务、AI 推理、自动数据采集、复杂权限角色。复盘日期显示而不发送通知。

## 归档与删除
归档后可以恢复；只有已归档记录才能永久删除。UI 必须输入完整标题确认，后端校验归档状态与最新版本。删除不可撤销，请先备份；删除不是安全擦除物理磁盘，历史备份也需单独管理。达到 500 项上限时，可在备份后删除不再需要的记录以释放容量。
